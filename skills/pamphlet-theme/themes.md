# 内置主题清单（13 套）

| 名字 | 写什么用它 |
|---|---|
| `default` | 通用中性：GitHub 那套色，最不抢内容 |
| `minimal` | 极简：黑白灰、窄栏、衬线标题、大留白 |
| `tech-dark` | 技术风：等宽标题、方角、青色强调 |
| `editorial` | 编辑部：大号衬线标题、章节编号、细分隔线，像杂志内页 |
| `console` | 控制台：等宽为骨、高密度、状态色，像一块盯着看的面板 |
| `paper` | 学术：窄正文列 + 边注、编号标题、无圆角，像一篇论文 |
| `fiction` | 小说：窄栏、首行缩进、段间不留空，为连续阅读排的版 |
| `manual` | 技术文档：代码块是主角、表头吸顶、斑马纹长表格 |
| `prd` | 需求文档：每节一条带编号的需求、验收清单、约束卡片 |
| `architecture` | 系统设计：图占最宽画布、引用块是决策记录、三线表摆取舍 |
| `blueprint` | 详细设计：三级编号、紧凑字段表、等宽标题，密度优先 |
| `incident` | 故障报告：步骤变时间轴、危险色压过一切、影响面表格 |
| `lesson` | 教学讲义：暖纸窄栏、衬线正文、等宽眉批、旁注靠一条左线 |
