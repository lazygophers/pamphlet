# frontmatter reference

**There is no config file.** All configuration lives in the frontmatter at the top of the source document — the part between the two `---` lines.

```yaml
---
spec: 1
title: Architecture plan
lang: en
toc:
  enable: true
  deep: 3
---
```

The reasoning: one source document = one artifact, so configuration travels with the document and copying the document copies its settings. A separate config file adds one more place for "the document is here, the settings are over there" to drift apart.

## Known fields

There are six. Anything else reports `DOC-102` as a warning and lists them — **not silently ignored**, because silence would let you believe the setting took effect.

| Field | Type | Default | Meaning |
|---|---|---|---|
| `spec` | integer | absent = no check | Minimum compiler syntax version this document requires |
| `title` | string | first `#` heading | The artifact's `<title>` |
| `theme` | string | — | ⚠️ see below |
| `lang` | string | `zh-CN` | The artifact's `<html lang="…">` |
| `toc` | boolean or object | off | Table of contents |
| `engines` | object | — | ⚠️ not implemented yet |

## spec

```yaml
spec: 1
```

Its role is **singular: marking "this is a pamphlet source document"**. The current compiler supports version `1`.

A value higher than the compiler supports reports `DOC-101` and suggests upgrading. A non-integer reports `DOC-103`.

It **no longer** triggers multi-parser behaviour — one parser is maintained. See [the versioning promise](/en/limits/versioning).

## title

```yaml
title: Architecture plan
```

If omitted, the compiler looks for the first `#` level-one heading in the document, and falls back to the literal string `pamphlet`.

## theme

:::warning This field currently does nothing
`theme` is parsed and validated (a non-string reports `DOC-103`), but **no code reads it**.

`@pamphlet/themes` defines three built-in theme names (`default` / `tech-dark` / `minimal`), but they are not wired into the compiler yet.

The only styling layer available today is the [theme tokens](/en/reference/theme-tokens).
:::

## lang

```yaml
lang: en
```

Written into the artifact's `<html lang="…">`. Default `zh-CN`.

It affects how screen readers pronounce the text and how browsers do line breaking and spell checking; it changes no compiler behaviour.

## toc

Shortest form:

```yaml
toc: true
```

Full form:

```yaml
toc:
  enable: true
  deep: 3
  skipTabs: true
  position: top
```

| Sub-field | Type | Default | Meaning |
|---|---|---|---|
| `enable` | boolean | `false` | Without turning it on there is no table of contents |
| `deep` | integer 1–6 | `2` | How many heading levels to include |
| `skipTabs` | boolean | `true` | Skip headings generated by tabs |
| `position` | `top` / `side` | `top` | `side` is not implemented |

The table of contents is **entirely static**: a nested list of anchor links, zero JavaScript.

Level-one headings (`#`) are excluded — that is the document title itself. A `deep` outside 1–6 reports `DOC-103`.

### Why skipTabs defaults to true

Tab panels are semantically **several views of one topic**; listing them in the table of contents makes readers think they are separate sections.

But tab labels are made into **real headings** for accessibility and deep linking, so they inevitably enter the document outline — which is why the table of contents side needs this switch.

### position: side is an error

```yaml
toc:
  position: side
```

Reports `DOC-104` as an **error**, not a warning, suggesting `position: top` instead.

Erroring rather than silently degrading to `top` is deliberate: a silent degrade would let you believe the sidebar was working and merely unstyled.

## engines

```yaml
engines:
  myengine:
    langs: [foo]
    command: [mytool, --svg]
```

:::warning Not implemented yet
Writing this reports `DOC-104` as a warning: custom engines are not implemented and the declaration has no effect. Built-in engines keep working.
:::

The eventual shape is already decided: diagram source in on stdin, SVG out on stdout, declarative, no plugin code to write.

## Diagnostics point at the field

Frontmatter diagnostics point at **the line of the offending field**, not vaguely at the `---`:

```
error[DOC-103] toc.deep 必须是 1 到 6 之间的整数
  --> plan.md:5:3
  |
5 |   deep: 9
  |   ^^^^
```
