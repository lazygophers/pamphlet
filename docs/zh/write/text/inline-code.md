# 行内代码

## 这是什么

句子中间那一小段等宽字：命令名、文件路径、字段名、按键。

和[代码块](/write/blocks/code)的区别是：行内代码**夹在一句话里**，代码块**自己占几行**。

## 怎么写

```markdown
跑 `pamphlet build 方案.md` 就行，产物写在 `方案.html`。
```

里面的内容**原样显示**——星号、井号、方括号都不会被当成语法：

```markdown
`**这四个星号会原样显示**`
```

## 内容里要写反引号

外面用**两个**反引号包起来，并且两边各留一个空格：

```markdown
`` 这里面有 ` 反引号 ``
```

规则是：外层的反引号个数比内层多。

## 出来是什么样

底色走主题的 `--pf-code-bg`，字体走 `--pf-font-mono`。`console` 和 `blueprint` 这两套主题整篇都是等宽字，行内代码和正文的差别主要靠底色。

## 坑

- **别拿它当强调用**。行内代码的意思是「这是机器认的字符串」，拿它标重点会让读者以为那是个命令
- 中文和行内代码之间不需要加空格，排版会自己处理间距
