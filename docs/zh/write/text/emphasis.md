# 强调

## 这是什么

把一段话里的几个字标出来：粗体、斜体、删除线。

## 怎么写

```markdown
**粗体** 或 __粗体__
*斜体* 或 _斜体_
***又粗又斜***
~~删除线~~
```

## 出来是什么样

- **粗体** → `<strong>`，屏幕阅读器会加重读
- *斜体* → `<em>`。**中文没有真正的斜体**，浏览器会把方块字强行倾斜，通常不好看——中文里想强调，优先用粗体
- ~~删除线~~ → `<del>`，用来表示「这条作废了但保留痕迹」

删除线是 GFM 扩展（GitHub 那套 Markdown 扩展），不是标准 Markdown 的一部分，但本站和 GitHub 都支持。

## 坑

- **中文之间用星号，别用下划线**。`__粗体__` 这种写法要求两侧是空格或标点，夹在中文里（`这是__粗体__字`）不生效，星号没有这个限制
- 星号和中文之间不要加空格：`** 粗体 **` 不是粗体
- 想强调一整段，用[提示块](/write/components/callout)，不要整段加粗——整段粗体等于没有强调
