# 转义

## 这是什么

让 `*` `_` `#` 这些有特殊含义的符号**显示成它本身**，而不是被当成语法。

## 怎么写

符号前面加一个反斜杠 `\`：

```markdown
\*这不是斜体\*
5 \* 3 = 15
\# 这不是标题
```

## 哪些符号需要转义

`\` `` ` `` `*` `_` `{}` `[]` `()` `#` `+` `-` `.` `!` `|`

**不必全背**：只有在那个位置真的会被当成语法时才需要转义。`5 * 3` 单独一个星号不会变成斜体，`3.14` 里的点也不会变成列表。

## 更省事的做法

短的一段直接用[行内代码](/write/text/inline-code)包起来，里面**什么都不用转义**：

```markdown
`**原样显示**`
```

## 坑

- **表格里的竖线要转义成 `\|`**，否则会被当成列分隔符，见[表格](/write/blocks/table)
- 反斜杠在行尾是[硬换行](/write/text/paragraphs)，不是转义
