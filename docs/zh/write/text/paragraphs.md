# 段落与换行

## 这是什么

正文的最小单位。**空行分段**，段与段之间由主题决定留多少空白。

## 怎么写

```markdown
这是第一段。

这是第二段。
```

连着写的两行属于**同一段**，产物里不会换行：

```markdown
这两行
在产物里是同一段。
```

真要在段内换行（写地址、写诗、写一条条的短句），两种写法：

```markdown
第一行在这里断开··
第二行

第一行在这里断开\
第二行
```

上面的 `··` 表示**两个空格**——实际写的时候看不见，所以**反斜杠那种更可靠**，也更容易在代码审查里被看见。

## 出来是什么样

段间距走主题的 `--pf-space-3`。少数主题会改写整套段落规则：

- `fiction`（小说）**首行缩进两个字，段与段之间不留空**——这是中文小说的排法
- `lesson`（讲义）把标题底下第一段放大成引言

## 坑

- **中文段落不要用空格对齐**，缩进两格是主题干的事，你自己敲空格会被当成代码块（四个空格开头 = 缩进式代码块）
- 连续多个空行等于一个空行，不会多留白。想拉开距离用[分隔线](/write/blocks/rule)或换主题
