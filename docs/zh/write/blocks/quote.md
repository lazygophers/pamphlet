# 引用块

## 这是什么

一段「别人说的话」或者「从别处摘来的话」，整块缩进或者带一条左线。

## 怎么写

```markdown
> 引用的话写在这里。
>
> 空行也要带上 `>`，否则算两段。
```

里面可以继续写别的：列表、代码块、粗体，甚至再套一层引用（`>>`）。

## 出来是什么样

**主题之间差别很大**：

| 主题 | 引用块长什么样 |
|---|---|
| 多数主题 | 左边一条竖线，文字压暗 |
| `paper` | 没有竖线，两边缩进，斜体 |
| `architecture` | 排成一条「**决策**」记录 |
| `fiction` | 作者旁白的样子 |

## 坑

- **别拿它当提示框用**。想提醒读者注意，用[提示块](/write/components/callout)（`:::warn`），它有明确的颜色语义；引用块的语义是「这话不是我说的」
- 引用块里每一行都要 `>`，包括空行。漏了就断成两个引用块
