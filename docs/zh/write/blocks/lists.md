# 列表

## 这是什么

三种：**无序**（圆点）、**有序**（数字）、**任务**（复选框）。

## 怎么写

### 无序

`-`、`*`、`+` 三个符号等价，**同一份文档里保持一致**就行：

```markdown
- 第一项
- 第二项
- 第三项
```

### 有序

```markdown
1. 第一步
2. 第二步
3. 第三步
```

**编号由浏览器算**，所以源文档里写 `1.` `1.` `1.` 也会渲染成 1、2、3。想从别的数字开始，把第一项写成那个数字（`3.` 开头就从 3 数起）。

### 任务列表

```markdown
- [x] 压测报告
- [ ] 灰度方案
```

复选框是**只读的**，读者点不动——产物是一份文档，不是一个待办应用。这是 GFM 扩展。

## 嵌套

子项**缩进到与上一层文字对齐**：无序列表缩 2 个空格，有序列表缩 3 个。

```markdown
- 第一项
  - 子项
    - 孙项

1. 第一步
   1. 子步骤
   2. 子步骤
```

## 一项里放多段、代码块、图片

同样按对齐缩进：

````markdown
1. **装一次**

   ```bash
   npm i -g @nekoleapuki/pamphlet-cli
   ```

2. **编译**

   得到 `方案.html`，双击打开。
````

## 紧凑与松散

列表项之间**有空行**时，每一项会被包成段落、行距变宽（术语叫「松散列表」）；没有空行就是紧凑的。想让列表看起来紧凑，项与项之间不要留空行。

## 坑

- **有序列表想做成带圆圈编号的操作步骤**，用[步骤](/write/components/steps)指令，不是普通有序列表
- 嵌套缩进少一格会被当成同级，多一格可能变成代码块——对齐到上一层的文字，不是对齐到符号
