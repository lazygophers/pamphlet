# 代码块

## 这是什么

自己占几行的一段代码或命令，等宽字、带底色、**按语言高亮**。

和[行内代码](/write/text/inline-code)的区别：行内代码夹在句子里，代码块自己独占一块。

## 怎么写

三个反引号包住，开头那行写语言名：

````markdown
```typescript
const a = 1
```
````

不写语言名就是纯文本，不高亮——贴报错日志、贴目录树用这个。

## 代码块里套代码块

**外层的反引号要比内层多**：

`````markdown
````markdown
```bash
echo 甲
```
````
`````

## 缩进式

每行缩进 4 个空格也算代码块。它和[列表](/write/blocks/lists)的缩进容易打架，**建议一律用三个反引号那种**。

## 出来是什么样

- 高亮在**编译时**做完，产物里不带任何高亮库
- 底色走主题的 `--pf-code-bg`
- `manual`（技术文档）这套主题让代码块当主角：左侧一条色条、更大的内边距
- 太长的行**横向滚动，不折行**——折行会让缩进失去意义

## 坑

- 语言名写错（`typescrpt`）不报错，只是不高亮
- 围栏语言写 `mermaid` 时**它不再是代码，而是一张图**，见[图表](/write/diagrams/flowchart)
