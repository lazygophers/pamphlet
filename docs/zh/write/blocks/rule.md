# 分隔线

## 这是什么

横跨一整行的一条线，用来把内容切成互不相干的两块。

## 怎么写

单独一行写三个或更多的 `-`、`*`、`_`：

```markdown
---
```

## 出来是什么样

一条 `<hr>`，颜色走主题的 `--pf-border`。

`fiction`（小说）这套主题把它换成**居中的三个点**——那是中文小说里的场景分隔符，不是一条线。

## 坑

:::warning 文档开头的 `---` 是 frontmatter
源文档**最开头**那对 `---` 之间的内容是配置（见 [frontmatter 参考](/reference/frontmatter)），不是分隔线。想让文档第一行就是分隔线，改用 `***`。
:::

- 分隔线前后都要留空行，否则 `---` 会把上一行变成二级标题（那是 Markdown 的另一种标题写法）
- 用它来「拉开距离」是滥用：章节之间该用[标题](/write/text/headings)
