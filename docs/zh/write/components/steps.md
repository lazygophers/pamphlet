# 步骤

## 这是什么

一串**按顺序做**的操作，每一步带一个编号圆圈。

和普通[有序列表](/write/blocks/lists)的区别：步骤强调「照着做」，视觉上更重。

## 怎么写

```markdown
:::steps
1. 装依赖
2. 改配置
3. 重启
:::
```

| 指令标题 | 属性 |
|---|---|
| — | 不接受 |

**里面必须是一个有序列表**。写成无序列表（`-`）或纯段落会报 `DIR-204`：`steps 里需要一个有序列表`。

## 每一步可以很长

列表项里可以放段落、代码块、图片，缩进对齐即可：

````markdown
:::steps
1. **装依赖**

   ```bash
   npm i -g @nekoleapuki/pamphlet-cli
   ```

2. **编译**

   得到 `方案.html`，双击打开。
:::
````

## 出来是什么样

编号变成圆圈。**编号由浏览器算**（CSS 的 `counter`），所以源文档里写 `1.` `1.` `1.` 也会正确渲染成 1、2、3。

`incident`（故障报告）这套主题把步骤变成**时间轴**：一条竖线加红点。

**关掉 JavaScript 完全不受影响**——步骤是纯 CSS，没有任何脚本参与。

## 坑

- **一步只做一件事**。一步里出现两个「然后再」就该拆
- 只有一步的步骤块没有意义，写成普通段落
