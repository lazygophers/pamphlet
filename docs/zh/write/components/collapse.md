# 折叠块

## 这是什么

默认收起、点一下展开的一段内容。放**大多数人不用看的细节**：完整配置、原始日志、附录。

## 怎么写

```markdown
:::collapse[点开看细节]
这里是折叠起来的内容。
:::

:::collapse[这个默认是展开的]{open}
加 `{open}` 就默认展开。
:::
```

| 指令标题 | 属性 |
|---|---|
| **必填** | `open` |

**指令标题必填**，没有报 `DIR-204`。理由很实在：无 JavaScript 时它降级成浏览器原生的 `<details>`，指令标题就是那个 `<summary>`——没有它就连可点的部分都没有。

## 出来是什么样

一个带三角的标题行，点开露出内容。

**关掉 JavaScript 时变成浏览器原生的 `<details>`，照样能点开**，`{open}` 对应 `<details open>`。这一个指令是几个交互指令里降级最干净的：浏览器原生就有对应元素。

有 JavaScript 时多做一件事：展开时把指令标题写进网址，方便你把「展开状态」直接发给别人。

## 坑

- **别用它藏关键信息**，理由同[标签页](/write/components/tabs)：内容一直在 DOM 里，搜索也搜得到
- `{open}` 只留给「多数人要看、但占地方」的那种。默认展开的折叠块，意义只剩下「可以收起来」
