# 思维导图

## 这是什么

一个中心词发散出去的树。

## 什么时候用

列提纲、梳理一个概念有哪几个方面。

## 怎么写

````````````markdown
`````````mermaid
mindmap
  root((Pamphlet))
    语法
      指令
      图表围栏
    主题
      配色
      版式
`````````
````````````

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- **靠缩进表示层级**，不用画箭头
- `root((文字))` 是双括号，画成圆形
- 超过三层就该考虑改用[列表](/write/blocks/lists)——思维导图的优势在「一眼看到全貌」，层数多了就没这个优势了
