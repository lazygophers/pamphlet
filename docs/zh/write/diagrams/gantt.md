# 甘特图

## 这是什么

一条时间轴上，哪件事什么时候开始、做多久。

## 什么时候用

画排期、画一次发布的时间安排、画依赖顺序。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````markdown
:::gantt[一次改版的排期]
sections:
  设计
  实现
tasks:
  设计 : 定方案 : 2026-03-02 : 5d
  设计 : 评审 : after 定方案 : 2d
  实现 : 编译器改动 : after 评审 : 8d
:::
````

这种写法在 GitHub 上不会渲染。要 GitHub 也能看，用[甘特图的 Mermaid 围栏写法](/write/diagrams/mermaid/gantt)，画出来是同一张图。

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- 块名固定是 `sections:` 和 `tasks:`
- 任务行是四段：`阶段 : 任务名 : 开始 : 时长`，例如 `设计 : 定方案 : 2026-03-02 : 5d`
- **阶段名必须在 `sections:` 里声明过**，否则报 `DIAG-306` 并列出已声明的阶段
- 日期一律写 `YYYY-MM-DD`；`{axis=%m-%d}` 定的是横轴显示成什么样
