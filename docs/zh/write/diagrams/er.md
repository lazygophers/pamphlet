# 实体关系图

## 这是什么

几张表之间的关系：一对一、一对多、多对多。

## 什么时候用

画数据库设计、画领域模型。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````markdown
:::er[源文档和它的东西]
entities:
  源文档
  图表围栏
  资源
relations:
  源文档 -> 图表围栏 : 含有
  源文档 -> 资源 : 引用
:::
````

这种写法在 GitHub 上不会渲染。要 GitHub 也能看，用[实体关系图的 Mermaid 围栏写法](/write/diagrams/mermaid/er)，画出来是同一张图。

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- 块名固定是 `entities:` 和 `relations:`
- **每条关系都画成一对多（`||--o{`）**——要一对一或多对多，用 Mermaid 围栏
- 没参与任何关系的实体照样画出来，不会凭空消失
- 冒号后面是关系的名字，用动词（「含有」「引用」）
