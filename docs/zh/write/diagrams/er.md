# 实体关系图

## 这是什么

几张表之间的关系：一对一、一对多、多对多。

## 什么时候用

画数据库设计、画领域模型。

## 怎么写

````````````markdown
`````````mermaid
erDiagram
  源文档 ||--|| 产物 : 编译成
  源文档 ||--o{ 图表围栏 : 含有
  源文档 ||--o{ 资源 : 引用
`````````
````````````

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- `||--||` 一对一，`||--o{` 一对多，`}o--o{` 多对多
- 冒号后面是**关系的名字**，用动词（「含有」「引用」），不是名词
- 实体名可以写中文
