# 流程图

## 这是什么

一件事从头走到尾，中间有分支。**最常用的一种图**。

## 什么时候用

画业务流程、画判断分支、画一条链路的几个环节。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````````````markdown
:::flow[登录链路]{dir=LR}
nodes:
  request = "请求"
  cache = diamond "有缓存吗？"
  hit = "直接返回"
  miss = cylinder "查数据库"
edges:
  request -> cache
  cache -> hit : 有
  cache -> miss : 没有
:::
````````````

上面那种写法在 GitHub 上不会渲染。要 GitHub 也能看，用下面这种：

### 另一种写法：Mermaid 围栏

````````````markdown
`````````mermaid
flowchart LR
  A[请求] --> B{Redis 有吗}
  B -->|有| C[直接返回]
  B -->|没有| D[查数据库]
`````````
````````````

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- `LR` 是从左到右，`TD` 是从上到下。节点多时用 `TD`，节点少时 `LR` 更扁平
- `[方框]` `(圆角)` `{菱形判断}` `[(圆柱)]` `([胶囊])` 各有含义，别混用
- **梯形 `[/文字/]` 这种花哨形状会让 SVG 体积暴涨**（实测单张 103KB → 换成圆角后 18KB）
