# 块图

## 这是什么

方块按行列摆好，中间可以留空。**不表示流程，只表示排布**。

## 什么时候用

画内存布局、画协议字段、画一个页面分成几块。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````markdown
:::block[编译的三段]{columns=3}
blocks:
  方案.md | - | 方案.html
  解析 | 画图 | 组装
:::
````

上面那种写法在 GitHub 上不会渲染。要 GitHub 也能看，用下面这种：

### 另一种写法：Mermaid 围栏

````markdown
```mermaid
block-beta
  columns 3
  源文档["方案.md"] space 产物["方案.html"]
  解析 画图 组装
```
````

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- `columns 3` 定一行几格，`space` 占一个空格子
- 它不画箭头也不表示顺序，需要顺序用[流程图](/write/diagrams/flowchart)
- 目前还是 beta 语法，将来可能变
