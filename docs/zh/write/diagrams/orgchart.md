# 组织架构图

## 这是什么

上下级的树，自上而下展开。

## 什么时候用

团队结构、模块归属——层级一深，用流程图硬画会横向拉得很长。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````markdown
:::orgchart[技术团队]
members:
  技术部
  > 前端组
  >> 张三
  >> 李四
  > 后端组
  >> 王五
:::
````

**这一种 Mermaid 画不了**，所以没有「另一种写法」——它的 SVG 由 Pamphlet 自己算布局、自己生成。

## 出来是什么样

编译时就画好内联进产物，读者那边不下载任何绘图库、也不联网。颜色走那六个图表变量（`--pf-diagram-bg` / `line` / `fill` / `text` / `accent` / `muted`），所以换主题时它跟着变。

文字宽度是**按字符估算**的（中日韩字符算一个字宽，其余算 0.55），不量真实字体——换来的是这一种图**不需要浏览器**也能编译。

## 坑

- 层级靠 `>` 的个数，和[思维导图](/write/diagrams/mindmap)一致
- 横向位置按子树宽度分配，兄弟之间不会挤在一起
- 一棵树写完再写下一棵：顶层可以有多个
