# 网络拓扑图

## 这是什么

主机分布在哪些网段里，它们之间怎么连。

## 什么时候用

记录生产环境的网络结构——Mermaid 的架构图只有几个固定图标，画不了网段。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````````````markdown
:::topology[生产环境]
zones:
  dmz = "DMZ"
  app = "应用网段"
hosts:
  lb = dmz "负载均衡"
  web1 = app "web-01"
  web2 = app "web-02"
links:
  lb -- web1 : 443
  lb -- web2 : 443
:::
````````````

**这一种 Mermaid 画不了**，所以没有「另一种写法」——它的 SVG 由 Pamphlet 自己算布局、自己生成。

## 出来是什么样

编译时就画好内联进产物，读者那边不下载任何绘图库、也不联网。颜色走那六个图表变量（`--pf-diagram-bg` / `line` / `fill` / `text` / `accent` / `muted`），所以换主题时它跟着变。

文字宽度是**按字符估算**的（中日韩字符算一个字宽，其余算 0.55），不量真实字体——换来的是这一种图**不需要浏览器**也能编译。

## 坑

- 主机行的形状位置写的是**它属于哪个网段**：`lb = dmz "负载均衡"`
- `links:` 可以不写，只画网段和主机
- 链路标签写在 `:` 后面，一般放端口
