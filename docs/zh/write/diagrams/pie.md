# 饼图

## 这是什么

一个整体被分成几块，每块占多少。

## 什么时候用

画体积构成、画成本占比、画流量来源。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````markdown
:::pie[产物体积构成]
slices:
  图表 SVG : 48
  样式 : 17
  正文 HTML : 12
  运行时 : 9
:::
````

这种写法在 GitHub 上不会渲染。要 GitHub 也能看，用[饼图的 Mermaid 围栏写法](/write/diagrams/mermaid/pie)，画出来是同一张图。

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- 只有一个块：`slices:`
- 每行是 `名字 : 数值`，数值必须是数字，写成「很多」报 `DIAG-306`
- 名字里的引号由编译器补，自己不用加
- 超过六块的饼图没人读得出比例，改用[表格](/write/blocks/table)
