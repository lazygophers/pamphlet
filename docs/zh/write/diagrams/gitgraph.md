# git 分支图

## 这是什么

分支从哪里拉出来、在哪里合回去。

## 什么时候用

讲清一次发布的分支策略、复盘一次合并冲突。

## 怎么写

````````````markdown
`````````mermaid
gitGraph
  commit id: "初始"
  branch themes
  commit id: "十三套主题"
  checkout main
  merge themes
`````````
````````````

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- `branch` 拉分支，`checkout` 切回去，`merge` 合并
- `id:` 里的字符串要加引号
- 提交超过十个就挤成一条线，只画关键的几个
