# 系统上下文图（C4）

## 这是什么

站在最外面看：**谁在用这个系统，这个系统又依赖谁**。C4 模型的第一层。

## 什么时候用

给不懂技术的人讲「这东西在整个链条里的位置」。

## 怎么写

Pamphlet 自己的写法——**先列声明、再列关系**，十七种图共用这副骨架：

````markdown
:::c4[谁在用 Pamphlet]
actors:
  author = person "作者"
  pf = system "Pamphlet"
  reader = external "读者的浏览器"
relations:
  author -> pf : pamphlet build
  pf -> reader : 一个自包含的 HTML
:::
````

上面那种写法在 GitHub 上不会渲染。要 GitHub 也能看，用下面这种：

### 另一种写法：Mermaid 围栏

````markdown
```mermaid
C4Context
  title 谁在用 Pamphlet
  Person(author, "作者", "写 Markdown 的人")
  System(pamphlet, "Pamphlet", "把一份 .md 编译成一个 HTML")
  System_Ext(reader, "读者的浏览器", "双击打开产物")
  Rel(author, pamphlet, "pamphlet build")
  Rel(pamphlet, reader, "一个自包含的 HTML 文件")
```
````

## 出来是什么样

编译时就画成 SVG 内联进产物，**读者那边不下载任何绘图库、也不联网**。颜色跟着主题走，可以滚轮缩放、按住拖动、双击复位。

## 坑

- `Person` 是人，`System` 是自家系统，`System_Ext` 是外部系统（颜色会不同）
- 第一个参数是 ID（英文），后面两个是显示的名字和说明，可以写中文
- C4 还有 `C4Container` `C4Component` 两层，越往里越细
