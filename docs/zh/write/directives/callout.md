# 提示块

四种：`info` / `tip` / `warn` / `danger`。

```markdown
:::info[顺带一提]
中性信息。
:::

:::tip
小技巧。标题可以不写。
:::

:::warn[小心]
可能出问题。
:::

:::danger[别这么干]
一定会出问题。
:::
```

| 标题 | 属性 |
|---|---|
| 可选 | 不接受任何属性 |

## 没有 `callout` 这个指令

**`callout` 是这四种块的统称，不是能写的指令名。** 写 `:::callout` 会得到 `DIR-201` 警告，提示里会列出那四个真名。

## 长什么样

产物里每个提示块是**左边一条 3px 竖线**，颜色按类型走 `--pf-info` / `--pf-tip` / `--pf-warn` / `--pf-danger`；底色四种统一用 `--pf-bg-subtle`。

:::info 没有图标
提示块**不渲染任何图标**，四种的区别只在左边那条线的颜色。想加图标目前没有办法。
:::

## 怎么选

| 用哪个 | 什么时候 |
|---|---|
| `info` | 补充说明，不看也不影响 |
| `tip` | 有更省事的做法 |
| `warn` | 不注意会出问题 |
| `danger` | 这么做一定出问题，或者不可逆 |

四种在无 JavaScript 时表现完全一样 —— 它们本来就是纯 CSS，不带任何交互。
