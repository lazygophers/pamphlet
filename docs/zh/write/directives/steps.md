# 步骤

一串带编号圆圈的操作步骤。

```markdown
:::steps
1. 装依赖
2. 改配置
3. 重启
:::
```

| 标题 | 属性 |
|---|---|
| — | 不接受任何属性 |

## 里面必须是一个有序列表

写成无序列表（`-`）或纯段落会报 `DIR-204`：`steps 里需要一个有序列表`。

**编号由浏览器算**，Pamphlet 只负责把它做成圆圈样式（CSS 的 `counter`）。所以你在源文档里写 `1.` `1.` `1.` 也会正确地渲染成 1、2、3 —— 这是 Markdown 有序列表本来的行为。

## 每一步可以很长

列表项里可以放段落、代码块、图片，缩进对齐即可：

```markdown
:::steps
1. **装依赖**

   ```bash
   npm i -g @pamphlet/cli
   ```

2. **编译**

   得到 `方案.html`，双击打开。
:::
```

## 关掉 JavaScript 时

**完全不受影响** —— 步骤是纯 CSS，没有任何脚本参与。圆圈编号靠 `counter-increment` 和 `::before`。
