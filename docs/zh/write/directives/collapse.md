# 折叠块

默认收起，点标题展开。放细节、附录、大段配置。

```markdown
:::collapse[高级参数]{open}
默认展开。去掉 `{open}` 就是默认收起。
:::
```

| 标题 | 属性 |
|---|---|
| **必填** | `open` |

## 标题必填

没标题报 `DIR-204`。理由很实在：**无 JavaScript 时它降级成原生 `<details>`，标题就是 `<summary>`** —— 没标题就连可点的部分都没有。

## 关掉 JavaScript 时

变成浏览器原生的 `<details>`，照样能点开。`{open}` 对应 `<details open>`。

这一个指令是四个交互指令里降级最干净的：浏览器原生就有对应元素。
