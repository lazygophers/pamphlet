# serve

本地预览，源文档改了就自动重新编译并刷新页面。

```bash
pamphlet serve 方案.md
pamphlet serve 方案.md --port 8080
```

| 选项 | 缺省 |
|---|---|
| `--port <端口>` | `4321` |

刷新走 SSE（Server-Sent Events，服务器主动往浏览器推消息的一种标准做法），不需要你手动按刷新。

## 一次只能预览一个文件

通配符匹配到多个会报错退出 `2`。

预览是「盯着一份文档改」的场景，同时盯几份没有意义 —— 浏览器一次也只显示一个页面。

## 预览的产物和 build 出来的一样吗

一样。`serve` 走的是同一条编译管线，只是把结果送进内存里的 HTTP 服务器而不是写文件。

所以预览里看到的诊断、占位框、体积，跟 `build` 出来的完全一致。
