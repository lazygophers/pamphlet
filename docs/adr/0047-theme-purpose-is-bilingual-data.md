# 主题的那一句说明是双语数据，诊断只印中文

[0046](./0046-themes-carry-their-own-css.md) 给每套主题定了一句话，说清它适合哪一类文档。字段做了，**没有任何地方读它**——`DOC-106` 只列名字，文档站的一览表是另外手写的一份。

现在两个消费者都接到同一处：

- `DOC-106` 的建议里，每个名字后面跟着它的 `purpose.zh`
- 文档站 `/reference/themes` 的一览表和主题画廊都由 `docs/components/Themes.tsx` 从 `THEMES` 遍历生成

新增一套主题只写一次说明，两边同时更新。

## 字段叫 `purpose`，不叫 `label`

`label` 在本项目是**占好了的词**：`CONTEXT.md` 把「标题」定成指令的 `[label]` 部分，并把 `label` 列进 _Avoid_。这里存的是「写什么用它」，是用途说明不是标题，所以叫 `purpose`。

## 说明按语言键存一份，而不是「只有中文」

文档站是双语的，编译器诊断是中文的。这个错位是真的，两条路：

- **`purpose: Record<'zh' | 'en', string>`**（选中）。一条记录带两种语言，取的人拿页面的语言键索引就行——中英两个并排字段（`label` / `labelEn`）会逼每个消费处再分一次语言的岔，而表头已经是按语言键索引的了。代价是加一套主题要写两句而不是一句。
- **只留中文，把「英文站显示中文」记成已知限制**（落选）。英文页现在写的是真英文（`incident` 那行是 "incident reports, post-mortems"），换成中文是**倒退**——为了「单一真相」把已经对的东西弄坏，不划算。

也考虑过在文档站上放一份翻译表。落选：那正是这张票要消灭的东西——说明写在一个地方、翻译写在另一个地方，两边照样会漂。

**诊断维持中文单语。** 编译器所有诊断的文案都是中文（`没有叫 xxx 的主题`），只把主题说明改成双语会得到一条半中半英的提示。诊断要不要双语是另一件事，涉及全部 21 个码，不在这张票里。

## 十二行的建议怎么排

`hint` 原来是一行。十二套主题的名字加说明塞进一行，在终端里是一堵墙。

所以：**一套一行，名字用 `padEnd` 对齐成一列**，段首一句 `能用的是这 12 套：`。为此 `formatDiagnostic` 学会了多行 `hint`——续行按 `= ` 的宽度缩进，整段挂在同一个 `=` 底下，而不是顶到最左边冒充另一条诊断。这个能力是格式化器的，任何诊断都能用。

按用途分组（考虑过，落选）：分组名就是 `purpose.zh` 冒号前面那半句（「小说」「故障报告」），每组只有一到两套，等于在十二行中间插进十二个分组标题，更长也更难扫。

## Consequences

**`Theme` 多了一个必填字段。** 加一套主题要写中英两句说明，漏一句 TypeScript 直接不过。

**文档站构建依赖主题包的源码。** `rspress.config.ts` 里把 `@nekoleapuki/pamphlet-themes` 指到 `packages/themes/src/index.ts`，和 `vitest.config.ts` 的做法一致——指 `dist` 的话，建站前忘了 build 就会悄悄用上一次的旧数据。

**`docs/zh|en/reference/themes.md` 变成 `.mdx`。** 路由不变（`_meta.json` 写的是不带后缀的名字），页面里多一行 import。这是文档站里第一个 React 组件。

**主题画廊也从注册表遍历生成。** 一览表之外，每套主题的那一节（标题 + 说明 + 截图）也是 `ThemeGallery` 生成的：手写十二个 `![](/themes/x.png)` 时，删掉一套主题只会让图不再生成而页面照旧引它——构建通过，站上留下一个裂图。代价是这十二节不再进 Rspress 的页面右侧大纲（大纲只从 Markdown 的标题抽），换来的是「删一套主题不会留下裂图、加一套主题两页自动多一节」。

**每套主题的长说明留在文档站，不进注册表。** `purpose` 那一句是给挑主题的人和诊断看的，而画廊里那段细描述只服务文档站；`Themes.tsx` 里没写到的主题**回落到 `purpose`**，所以新增一套主题不写长说明也不会缺一节。

**`docs/components/*.tsx` 和 `rspress.config.ts` 进了 `tsc -b`**（`tsconfig.docs.json`）。原来它们不属于任何 TypeScript 项目，`pnpm typecheck` 看不见——改一个主题字段名，只有跑到文档站构建时才炸。

**多行 `hint` 会改动 golden 快照**——但只在真的用了多行的诊断上。现有诊断全是单行，走的是同一段代码，输出一个字节都没变。
